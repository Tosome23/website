위험물 MSDS 제출 방법 완전정리
MSDS만 있으면 수출됩니다

화학약품 수출을 준비했는데 "위험물이라서 어렵습니다"라는 말을 들으셨나요? 문제는 서류가 없어서가 아닙니다. MSDS 한 장만 있으면 투삼로지스가 UN번호 확인부터 DGD 작성, 항공사 승인까지 전부 처리합니다.

1. MSDS란? — 30초 정리

MSDS(Material Safety Data Sheet)는 물질안전보건자료입니다. 화학물질의 위험성, 취급 방법, 응급조치, 운송 정보 등 16개 항목을 담은 공식 문서로, 위험물 수출 시 항공사·선사·포워더 모두 MSDS를 요구합니다.

MSDS가 있어야 UN번호(UN Number)와 위험물 등급(Class)을 확인하고, 운송 가능 여부를 판단할 수 있습니다.

💡 핵심: MSDS는 위험물 수출의 출발점이자 가장 중요한 서류입니다. MSDS가 있으면 투삼로지스에 바로 전달하시면 됩니다.

2. 위험물 MSDS 제출 방법 — 5단계 완전 가이드

위험물 수출은 아래 5단계로 진행됩니다. 각 단계에서 무엇을 준비하고 어디에 제출하는지 정리했습니다.

01
MSDS 확보 및 내용 확인
제조사 또는 공급사로부터 영문 MSDS를 받습니다. 반드시 확인할 핵심 섹션은 3가지입니다.
섹션 9 — 물리화학적 특성 (인화점, 비중 등) 섹션 14 — 운송 정보 (UN Number, Class, Packing Group) 섹션 2 — 유해성·위험성 분류
02
UN번호·위험물 등급 확인
MSDS의 섹션 14를 기반으로 UN번호와 위험물 등급(Class)을 파악합니다. 섹션 14에 UN Number가 없거나 "해당 없음"으로 기재되어 있어도 실제로는 위험물일 수 있으므로, 전문 포워더에게 확인을 맡기는 것이 안전합니다.
03
포워더에 MSDS 제출
MSDS를 포워더에게 전달하면, 포워더가 운송 경로별 위험물 수락 여부, 포장 규격 적합성, 추가 서류 필요 여부를 검토합니다. 투삼로지스는 MSDS만 받으면 나머지를 모두 처리합니다.
운송 경로별 위험물 수락 여부 (항공사·선사별 규정 상이) 포장 규격 적합성 (UN 인증 용기 필요 여부) 추가 서류 필요 여부 확인
04
위험물 포장 및 라벨링
위험물은 일반 화물과 다르게 포장 규정이 엄격합니다. 투삼로지스는 위험물 자격증 보유 상담사가 포장 기준을 직접 안내합니다.
UN 인증 용기 사용 (용기에 UN 마크 표시) 위험물 라벨 부착 (등급별 다이아몬드 형태 라벨) 수량 제한 준수 (항공 기준 Limited Quantity 등)
05
최종 서류 제출 및 출고
포워더가 항공사 또는 선사에 서류를 일괄 제출합니다. 승인 완료 후 화물을 출고합니다. 투삼로지스는 당일 입고 → 당일 출고가 기본입니다.
MSDS (영문, 16개 항목 완전본) DGD / Shipper's Declaration 포장 사진 (요청 시) + 운송장 (AWB 또는 B/L)
✅ 고객이 직접 한 일 → MSDS 전달 1가지
그 외 UN번호 확인, DGD 작성, 항공사 승인, 포장 지도, 출고 스케줄 — 투삼로지스가 전부 처리

3. 위험물 등급(Class)별 필요 서류

위험물 등급에 따라 필요한 서류가 달라집니다. MSDS의 섹션 14에서 Class를 확인하고 아래 표를 참고하세요.

위험물 등급 (Class)대표 품목필요 서류
Class 1화약류MSDS + 수출허가서
Class 2가스류 (에어로졸, 냉매)MSDS + DGD
Class 3인화성 액체 (페인트, 잉크, 용제)MSDS + DGD
Class 4가연성 고체MSDS + DGD
Class 5산화성 물질MSDS + DGD
Class 6독성·감염성 물질MSDS + DGD + 별도 승인
Class 7방사성 물질MSDS + 원자력 관련 허가
Class 8부식성 물질 (산, 염기)MSDS + DGD
Class 9기타 위험물 (리튬배터리, 드라이아이스)MSDS + UN38.3 (배터리)
💡 DGD(Dangerous Goods Declaration): 위험물 화주신고서. 항공 운송 시 필수 제출 서류입니다. 투삼로지스에서 고객 대신 작성해드립니다.

4. MSDS 제출 전 체크리스트

수출 전에 아래 항목을 빠르게 점검해보세요. 하나라도 미비하면 출고가 지연될 수 있습니다.

1
MSDS 언어 — 영문 준비
영문 MSDS가 필수입니다. 한글 단독으로는 항공사·선사 제출이 불가합니다.
2
섹션 14 기재 여부
UN Number / Class / Packing Group이 섹션 14에 기재되어 있는지 확인하세요. 누락되어 있어도 전문가 확인으로 처리 가능합니다.
3
섹션 9 물리적 특성
인화점, 끓는점 등 물리화학적 특성이 기재되어 있는지 확인합니다. 위험물 분류 판단의 핵심 근거입니다.
4
MSDS 발행처
제조사 또는 공인기관 발행 여부를 확인합니다. 임의 작성 문서는 인정되지 않습니다.
5
수량 및 포장 용기
항공 Limited Quantity 기준 초과 여부, UN 인증 용기 사용 여부를 사전 확인합니다.
6
목적국 위험물 수락 여부
수입국마다 위험물 반입 규정이 다릅니다. 목적국 규제를 사전 확인하면 반송 리스크를 줄일 수 있습니다.

5. 투삼로지스가 다른 이유

많은 고객이 이런 고민을 합니다. "DGD를 직접 써야 하나요? UN번호는 어디서 찾나요?" 투삼로지스에서는 MSDS만 보내주시면 됩니다.

투삼로지스 위험물 서류 대행 항목
🔍MSDS 기반 UN번호·등급 확인
📋DGD / Shipper's Declaration 작성 대행
✈️항공사 위험물 승인 처리
📦포장 규격 안내 (위험물 자격증 보유 상담사)
🚀당일 입고 → 당일 출고 기본 제공
✅ Class 1~9 전 등급 처리 가능
✅ 소량 10g부터 접수
✅ 화학약품 70종 동시 수출 실적 보유

6. 이런 분이라면 투삼로지스로 오세요

아래 상황 중 하나라도 해당된다면 투삼로지스에 문의하세요. MSDS가 있으면 바로 시작할 수 있습니다.

  • MSDS가 있는데 다른 업체에서 거절당한 경우
  • UN번호가 나오는 화학약품인데 어디서 접수해야 할지 모르겠는 경우
  • 소량 샘플(10g~수백g)인데 위험물이라서 막힌 경우
  • 화학약품 여러 종류를 한 번에 수출해야 하는 경우
  • Class 1~9 전 등급 처리가 필요한 경우
⚠️ 위험물 처리 경험이 없는 업체를 만나면 MSDS가 있어도 수출이 막힙니다. 서류 문제가 아니라 업체 선택의 문제입니다.
